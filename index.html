Manual de Usuario Definitivo

Esta herramienta es tu Centro de Comando (MIPE). Automatiza la toma de decisiones utilizando algoritmos para evitar la resistencia cruzada, calcula volúmenes precisos y genera toda la documentación operativa (PDFs y Excels).
NOTA DE SEGURIDAD: Todos los datos se guardan comprimidos y cifrados en tu dispositivo, no dependes de internet para operar.

1. Pestaña: Base de Datos

Esta es la piedra angular del sistema. Aquí gestionas el "Inventario Maestro" de tus agroquímicos.

Cargar Archivo Excel:

Sube un Excel (.xlsx) con los datos de tus productos. La primera hoja debe llamarse BD. Columnas obligatorias: PRODUCTO, INGREDIENTE ACTIVO, DOSIS, TIPO DE AGROQUIMICO, CATEGORIA TOX, REENTRADA.

Bajar Backup (.json):

Exporta toda la memoria de tu aplicación (programas, históricos, lógicas) en un solo archivo. Hazlo semanalmente como copia de seguridad o para trasladar los datos a otra PC.

Subir Backup:

Restaura un archivo .sql o .json descargado previamente. Cuidado: Sobrescribirá toda la información actual por la que esté en el archivo.

Borrar Todo (Reset):

Botón de emergencia. Elimina ABSOLUTAMENTE TODO el contenido de la aplicación y la deja como nueva de fábrica. Irreversible sin un backup.

2. Pestaña: Lógica Universal (El Motor Inteligente)

Aquí le enseñas a la aplicación cómo pensar y qué decisiones tomar ante cada nivel de plaga o cronograma semanal.

Parámetros Globales:

Define los volúmenes de agua (L/Cama) que usas comúnmente separados por comas, y la lista de Equipos (Mochilas, Estacionarias) y Direcciones de aplicación. Estos alimentarán las listas desplegables del sistema.

1. Blancos Biológicos (Matriz de Rotación):
  • Haz clic en Nuevo Blanco para registrar una plaga (Ej: Ácaros).
  • Define la Base Fija (productos que siempre van) y Acompañantes (productos rotativos). Puedes usar + para tanques simultáneos o , para opciones separadas.
  • Regla (Umbral): Define qué combinación se dispara "Si la incidencia es >= al X%".
  • Lógica Interna (LRU): El sistema recuerda los productos que usaste en semanas anteriores. Si hay múltiples acompañantes que sirven para el mismo umbral, el algoritmo seleccionará el agroquímico "Menos Utilizado Recientemente" para evitar que las plagas creen resistencia.
2. Aplicaciones Fijas por Semana:

Para productos preventivos (nutricionales, fungicidas fijos) que se aplican sin importar la incidencia. Las aplicaciones fijas tienen prioridad absoluta sobre el algoritmo de Blancos Biológicos.

  • T1 (Principal) y T2 (Refuerzo): Puedes programar hasta 2 tanques preventivos distintos por semana.
  • Suelo / Drench: Columna especial para aplicaciones dirigidas a la raíz, separadas de los tanques foliares.
  • Alerta Roja: Si marcas esta casilla, el sistema destacará en rojo brillante esta aplicación como obligatoria y crítica en los reportes de campo.
Guardar Toda la Lógica: Ninguno de los cambios hechos en esta pestaña tendrá efecto hasta que presiones este botón al final de la página.

3. Pestaña: Programa de Cultivo

Aquí es donde introduces los datos del monitoreo para que el Motor Inteligente genere los tanques a preparar.

Ingreso de Datos: Ingresa el Nombre del Bloque (Sector), la Semana actual y las incidencias (porcentajes) reportadas por el equipo de monitoreo de plagas.

Botón "Generar Programa": Lee las incidencias ingresadas, cruza los datos con la Lógica Universal, consulta el historial para no repetir químicos, y calcula instantáneamente los tanques exactos, dosis y L/Cama recomendados.

Botón "Enviar a Operación" (Avión de Papel): Convierte el borrador del bloque actual y lo envía a la "Programación Operativa". Una vez enviado, el sistema considera el bloque listo para ejecución real en el campo.

Borrar Bloque: Elimina de la pantalla el bloque actual si te equivocaste ingresando datos.

4. Pestaña: Programación Operativa

La sala de control para el Jefe MIPE o Operador. Muestra todas las aplicaciones agrupadas en "Tanques de Mezcla". Desde aquí se coordina la logística.

Manual

Usa este botón en la barra superior para crear un tanque 100% vacío desde cero si necesitas una aplicación que no salió del programa lógico. Luego usa el botón (+) de ese tanque para ir sumando productos uno por uno.

Pegar

Clonación rápida. En cualquier tanque (fila) presiona el icono de Copiar (Celeste claro). Luego, en la barra superior presiona Pegar (Verde) y automáticamente se creará una copia idéntica lista para asignar a otro bloque o día.

Botón verde claro ubicado dentro de cada tanque. Sirve para buscar e incluir rápidamente cualquier producto de tu base de datos a ese tanque específico.

Orden Compra

Resume matemáticamente lo que consumirás en esta pantalla operativa, generándote un informe de cantidades exactas en L/Kg para pedir a bodega los químicos necesarios.

Botón rojo de la fila para borrar todo el tanque si te equivocaste o si la labor se canceló.

Botón de la fila para archivar ese tanque INDIVIDUALMENTE al historial, en lugar de usar el botón superior que archiva todos juntos al mismo tiempo.

Botón "Archivar Histórico"
Este botón es sagrado. Cuando presiones "Archivar Histórico", todos los tanques mostrados desaparecerán de aquí y se guardarán permanentemente en el "Histórico de Aplicaciones". Representa que la labor ya fue ejecutada o consolidada.

5. Pestaña: Histórico de Aplicaciones y Reportes

Toda la información archivada vive aquí. Es tu fuente principal para auditar, exportar estadísticas y generar la papelería en PDF.

Prog. Campo Almacén Etiquetas Calendario Descargar Excel
  • Prog. Campo (Programa de Fumigación Semanal): Genera un PDF apaisado, ordenado por días de la semana y horas. Muestra a los operarios exactamente a qué bloque ir, qué tanque preparar, y todos los parámetros técnicos (pH, Vol. Tanque, Dosis, Reentradas). Está optimizado para ajustarse automáticamente en 1 hoja por día.
  • Almacén (Reporte de Salidas): Genera un PDF estructurado como una orden de despacho para el bodeguero. Suma los consumos agrupados por tanque/día e indica la firma de responsabilidad.
  • Etiquetas: Imprime un PDF con formato de etiqueta térmica estándar (100mm x 50mm). Crea 1 etiqueta por cada producto a preparar, conteniendo Ingrediente Activo, Toxicidad visual (franja de color automática según la categoría del producto), dosis y advertencias de seguridad.
  • Calendario: Dibuja una tabla visual matricial (Bloques vs Días de la Semana) señalando en qué día y hora caen los tratamientos (ej. INSECTICIDAS/ACARICIDAS). Excelente mapa gerencial.
  • Descargar Excel: Baja toda la sábana de datos crudos (CSV/Excel) de esa semana filtrada para realizar tablas dinámicas u otros reportes externos.
  • Botón "Dev." (Devolver): Si al revisar el histórico te das cuenta de que algo se archivó con un error o no se aplicó por lluvias, presiona este botón amarillo en la fila correspondiente. El tanque se borrará del histórico y regresará mágicamente a la "Programación Operativa" para que lo corrijas y lo vuelvas a archivar.

📖 Quick Guide: Unified Log

This tool is designed to automate, organize, and streamline decision-making, operational scheduling, and report generation in your crop. Since the data is saved directly on your device, it is fast and secure. Here is a step-by-step guide on how to use it.

Step 1: Load Database (Excel)

  • Go to the Database tab.
  • Click the green Load Excel File button and upload your product inventory.
  • *Important:* Your Excel must contain clear headers like: `PRODUCTO`, `INGREDIENTE ACTIVO`, `DOSIS`, `BLANCO BIOLOGICO`, `TIPO DE AGROQUIMICO`, `CATEGORIA TOX` and `REENTRADA`.

Step 2: Configure Universal Logic

  • Go to the Universal Logic tab.
  • Global Parameters: Define L/Bed (Options), Equipment, and Directions separated by commas.
  • 1. Biological Targets (Rotation): Click New Target to add pests or diseases. Write the Bases and Companions separated by commas (,) or plus (+). Define the Rules if incidence is below or above threshold.
  • 2. Fixed Weekly Applications: If you have a schedule (e.g. preventatives), enter the products in the corresponding week.
    • These fixed applications override the automatic rotation.
    • You can set a Main (T1) and a Booster (T2).
    • Use the Red Alert checkbox to visually highlight the application.
    • Includes an exclusive column for Soil / Drench applications.
  • Click the green Save All Logic button.

Step 3: Create a Crop Program

  • Go to the Crop Program tab. Enter the Block Name, Week, and Incidences (%).
  • Click Generate Program. The system will suggest the ideal tanks avoiding product repetition.
  • Click the blue Send to Operation button (paper airplane icon).

Step 4: Operational Schedule

  • Go to the Operational Schedule tab to see grouped tanks ready to apply.
  • You can manually change details: day, equipment, L/Bed, or swap a product.
  • Useful tools: Manual (adds blank rows), Paste (copied recipes), Purchase Order (generates a PDF with needs).
  • When applied, click the purple Archive History button.

Step 5: History and PDF Reports

  • Go to Application History and select the Week.
  • PDF Reports: Use top buttons to print Field Prog., Warehouse, Labels (100x50mm) and Calendar.
  • Made a mistake? Use the Return button to send the tank back to the Operational Schedule.

Step 6: Backups

  • It is vital to download backups. Go to Database and click Download Backup.
  • To transfer the app to another computer, send that .json file and use Upload Backup.
  • To start a new season, use the red Delete All (Reset) button. Warning! It is irreversible without a backup.

📖 Guia Rápido: Diário Unificado

Esta ferramenta foi projetada para automatizar, organizar e agilizar a tomada de decisões, a programação operacional e a geração de relatórios no seu cultivo. Como os dados são salvos no seu dispositivo, é muito rápida e segura. A seguir, explicamos como utilizá-la passo a passo.

Passo 1: Carregar Banco de Dados (Excel)

  • Vá para a aba Banco de Dados.
  • Clique no botão verde Carregar Arquivo Excel e envie seu inventário.
  • *Importante:* Seu Excel deve conter cabeçalhos claros como: `PRODUCTO`, `INGREDIENTE ACTIVO`, `DOSIS`, `BLANCO BIOLOGICO`, `TIPO DE AGROQUIMICO`, `CATEGORIA TOX` e `REENTRADA`.

Passo 2: Configurar a Lógica Universal

  • Vá para a aba Lógica Universal.
  • Parâmetros Globais: Defina L/Cant (Opções), Equipamentos e Direções separados por vírgulas.
  • 1. Alvos Biológicos (Rotação): Clique em Novo Alvo para adicionar pragas. Escreva os produtos Bases e Acompanhantes separados por vírgulas (,) ou mais (+). Defina as Regras se a incidência for menor ou maior que o limiar.
  • 2. Aplicações Fixas por Semana: Se você tem um cronograma (ex. preventivos), insira os produtos na semana correspondente.
    • Estas aplicações fixas prevalecen sobre a rotação automática.
    • Você pode configurar um Principal (T1) e um Reforço (T2).
    • Use a caixa Alerta Vermelho para destacar a aplicação.
    • Inclui coluna exclusiva para programar aplicações ao Solo / Drench.
  • Clique no botão verde Salvar Toda a Lógica.

Passo 3: Criar Programa de Cultivo

  • Vá para Programa de Cultivo. Insira o Bloco, a Semana e as Incidências (%).
  • Clique em Gerar Programa. O sistema sugerirá os tanques ideais evitando repetir produtos.
  • Clique no botão azul Enviar à Operação (ícone de avião).

Passo 4: Programação Operacional

  • Vá para Programação Operacional para ver os tanques prontos para aplicar.
  • Você pode alterar detalhes manualmente: dia, equipamento, L/Cant ou trocar um produto.
  • Ferramentas úteis: Manual (linhas em branco), Colar (receitas copiadas), Ordem de Compra (gera PDF com necessidades).
  • Quando tudo estiver aplicado, clique no botão roxo Arquivar Histórico.

Passo 5: Histórico e Relatórios PDF

  • Vá para Histórico de Aplicações e selecione a Semana.
  • Relatórios PDF: Use os botões superiores para imprimir Prog. Campo, Armazém, Etiquetas (100x50mm) e Calendário Automático.
  • Errou? Use o botão Devolver (Dev.) para retornar o tanque à Programação Operacional.

Passo 6: Cópias de Segurança (Backups)

  • É vital baixar backups. Vá para Banco de Dados e use Baixar Backup.
  • Para passar o aplicativo para outro computador, envie o arquivo .json e use Subir Backup.
  • Para iniciar uma nova temporada, use o botão vermelho Apagar Tudo (Reset). Atenção! É irreversível sem um backup.

Sobre Nosotros: Nuestro Propósito

Optimizando la gestión agrícola mediante tecnología, organización y principios agroecológicos.

La Problemática

En la agricultura de precisión, la programación de aplicaciones fitosanitarias suele depender de hojas de cálculo aisladas, procesos manuales o la memoria del equipo técnico. Esto genera un alto riesgo de error humano, sobredosificaciones, desorganización y, lo más crítico: la repetición accidental de ingredientes activos. Esta mala práctica acelera la resistencia en plagas y enfermedades, elevando los costos de producción y el impacto ambiental.

Nuestro Objetivo

La Bitácora Unificada de Fumigación fue creada para ser la solución definitiva a este desafío. Nuestro objetivo es proporcionar un Motor de Lógica Universal que analice los umbrales de plagas y genere automáticamente cronogramas de aplicación perfectos. El sistema garantiza la rotación adecuada de productos (LRU), calcula volúmenes exactos, emite órdenes de compra y protege la salud del cultivo y del operario.

Nuestra Visión

Creemos firmemente en el poder de democratizar la tecnología en el campo. Buscamos empoderar a los equipos de Manejo Integrado de Plagas y Enfermedades (MIPE) liberándolos de la carga administrativa. Al automatizar la planificación operativa, permitimos que el talento humano se enfoque en el análisis en terreno, logrando fincas más productivas, sostenibles, rentables y ecológicamente responsables.
